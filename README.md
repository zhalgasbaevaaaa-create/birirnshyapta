# Қазақстанның тас дәуірі — тарихи пазл

Қазақстан аумағындағы Тас дәуірі тақырыптарына арналған интерактивті білім беру ойыны. Ойынның негізгі идеясы: **сұраққа жауап бер → пазлдың бір бөлігін аш → тарихи суретті толық жина**.

## Ойын ережесі

- Ойын **3 жанмен** басталады: `♥ ♥ ♥`.
- Барлығы **38 сұрақ пен пазл бөлігі** бар.
- Әр сұрақта 4 жауап нұсқасы беріледі, оның біреуі ғана дұрыс.
- Дұрыс жауап үшін `+1 ұпай` беріледі және тарихи суреттің бір пазл бөлігі ашылады.
- Қате жауапта 1 жан жоғалады. Ұпай шегерілмейді.
- Дұрыс жауап жанды қалпына келтірмейді.
- Қате жауаптан кейін жан қалған болса, сол сұраққа қайта жауап беруге болады.
- 3 жанның бәрі жоғалса, ойын аяқталады.
- Барлық 38 бөлік ашылса, ойын жеңіспен аяқталады.
- `ҚАЙТА БАСТАУ` немесе `ҚАЙТА ОЙНАУ` батырмасы ұпайды 0-ге, жанды 3-ке және жабық пазлға қайтарады.

## Мазмұны

Сұрақтар тек Қазақстан аумағындағы Тас дәуіріне қатысты: палеолит, мезолит, неолит, алғашқы адамдардың тұрмысы, аңшылық, терімшілік, отты пайдалану, тас құралдар, үңгір өнері және Қазақстандағы тас дәуірі тұрақтары.

Пазлдың артындағы тарихи иллюстрация осы жоба үшін арнайы AI көмегімен жасалды. Сыртқы сурет немесе сыртқы кітапхана қолданылмайды.

## Технологиялар

- HTML5
- CSS3 (responsive layout, animation, embedded visual styling)
- Vanilla JavaScript (ES2020+)
- PNG тарихи иллюстрациясы — `assets/stone-age-kazakhstan.png`

## Іске қосу

Жоба статикалық болғандықтан, серверлік тәуелділіктер қажет емес.

```bash
python3 -m http.server 8080
```

Содан кейін браузерден `http://localhost:8080` адресін ашыңыз.

Немесе кез келген статикалық hosting қызметіне репозиторийдің мазмұнын жариялауға болады. GitHub Pages үшін `main` тармағын және root (`/`) каталогын таңдаңыз.

## Файлдар

- `index.html` — ойынның семантикалық құрылымы
- `styles.css` — тас, қоңыр және құм түстеріндегі responsive интерфейс
- `app.js` — 3 жан, ұпай, сұрақ, жауап, пазл және аяқталу логикасы
- `assets/stone-age-kazakhstan.png` — біртұтас Тас дәуірі иллюстрациясы
