# Қазақстанның тас дәуірі — ҰБТ үлгісіндегі тарихи пазл

Қазақстан аумағындағы Тас дәуірі тақырыптарына арналған интерактивті білім беру ойыны. Ойынның негізгі идеясы: **сұраққа жауап бер → пазлдың бір бөлігін аш → тарихи суретті толық жина**.

Сұрақтар ҰБТ-ға дайындыққа ыңғайлы бір дұрыс жауапты төрт нұсқалы форматта құрастырылды. Ойын мазмұны палеолит, мезолит, неолит, алғашқы адамдардың тұрмысы және Қазақстандағы тас дәуірі тұрақтарына шоғырланған.

## Ойын ережесі

- Ойын **5 жанмен** басталады: `♥ ♥ ♥ ♥ ♥`.
- Барлығы **42 сұрақ пен пазл бөлігі** бар.
- Әр сұрақта 4 жауап нұсқасы беріледі, оның біреуі ғана дұрыс.
- Дұрыс жауап үшін `+1 ұпай` беріледі және тарихи суреттің бір пазл бөлігі ашылады.
- Дұрыс жауаптардың орны сұрақ сайын ауысып отырады.
- Әр сұраққа **10 секунд** беріледі.
- 10 секунд ішінде жауап берілмесе, **1 жан күйеді**. Уақыт біткен сұраққа қалған жан бар болса қайта жауап беруге болады.
- Қате жауапта 1 жан жоғалады. Ұпай шегерілмейді.
- Дұрыс жауап жанды қалпына келтірмейді.
- 5 жанның бәрі жоғалса, ойын аяқталады.
- Барлық 42 бөлік ашылса, ойын жеңіспен аяқталады.
- `ҚАЙТА БАСТАУ` немесе `ҚАЙТА ОЙНАУ` батырмасы ұпайды 0-ге, жанды 5-ке, уақытты 10 секундқа және жабық пазлға қайтарады.

## Мазмұнды тексеру

Сұрақтар Қазақстан тарихының тас дәуірі тақырыптарына қайта қаралып құрастырылды: палеолиттің кезеңдері мен мерзімдері, мезолиттің микролиттері мен садақ-жебесі, неолиттің тас өңдеу тәсілдері мен неолиттік төңкеріс, алғашқы қауымның тұрмысы және Бөріқазған, Тәңірқазған, Шақпақата, Атбасар, Мақанжар, Қараүңгір, Усть-Нарым, Сексеуіл сияқты тұрақтар.

Пазлдың артындағы тарихи иллюстрация осы жоба үшін арнайы AI көмегімен жасалды. Сыртқы сурет немесе сыртқы кітапхана қолданылмайды.

## Технологиялар

- HTML5
- CSS3 (responsive layout, таймер түстері, puzzle animation)
- Vanilla JavaScript (ES2020+)
- PNG тарихи иллюстрациясы — `assets/stone-age-kazakhstan.png`

## Іске қосу

Жоба статикалық болғандықтан, серверлік тәуелділіктер қажет емес.

```bash
python3 -m http.server 8080
```

Содан кейін браузерден `http://localhost:8080` адресін ашыңыз.

Немесе кез келген статикалық hosting қызметіне репозиторийдің мазмұнын жариялауға болады. GitHub Pages үшін `main` тармағын және root (`/`) каталогын таңдаңыз.

## Файлдар

- `index.html` — ойынның семантикалық құрылымы, көрсеткіштер және 10 секундтық таймер интерфейсі
- `styles.css` — тас, қоңыр және құм түстеріндегі responsive интерфейс
- `app.js` — 42 сұрақ, 5 жан, таймер, ұпай, жауап, пазл және аяқталу логикасы
- `assets/stone-age-kazakhstan.png` — біртұтас Тас дәуірі иллюстрациясы
